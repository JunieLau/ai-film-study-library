# AI Film Study Library · AI 影像学习资料库

A static, bilingual study index with three source sections: Higgsfield, PJ Ace and JBOOGXCREATIVE. The interface supports Chinese, English and bilingual view, with search, filters and browser-local learning progress.

This is an independent index, not an official site of any of the creators or services. Listings and summaries refer readers to their original sources. Image ownership stays with the original creators. The site does not host courses, videos, membership-only content, or Skill packages.

For GitHub Pages, set **Settings → Pages → Deploy from a branch → main → / (root)**.
